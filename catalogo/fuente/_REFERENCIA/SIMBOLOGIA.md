## Escala de destonificación de color

| Código | Descripción |
| --- | --- |
| V1 | Aspecto uniforme. Todas las piezas de la misma partida son similares. |
| V2 | Variación leve. Diferencias claramente perceptibles en textura y/o diseño, pero con colores similares. |
| V3 | Variación moderada. La intensidad del color y/o diseño de cada pieza puede variar significativamente. |
| V4 | Variación alta. El color y/o diseño es aleatorio entre baldosas, de manera que cada una puede tener colores completamente diferentes. |
